# Integration logos

These are unmodified official assets, bundled locally. Keep the originals intact.
Provider names appear alongside the marks in the UI.

- Slack: https://slack.com/media-kit — `SLA-Slack-icon-black-RGB.svg` and `SLA-Slack-icon-white-RGB.svg` from the [official logo collection](https://salesforce.widencollective.com/c/yn6bxnam).
- Discord: https://discord.com/branding — https://cdn.prod.website-files.com/6257adef93867e50d84d30e2/66e3d7f4ef6498ac018f2c55_Symbol.svg
- GitHub: https://brand.github.com/foundations/logo — `GitHub_Invertocat_Black.svg` and `GitHub_Invertocat_White.svg` from https://brand.github.com/GitHub_Logos.zip

The Slack and GitHub black and white variants are selected for light and dark themes.
Logos remain the property of their respective owners and follow their brand guidelines.
