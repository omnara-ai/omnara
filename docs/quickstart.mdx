This guide creates a simple research agent, launches it from the console, and shows where to inspect its timeline.

You need an Omnara account and a model provider API key.

## Create an agent profile

<Steps>
  <Step title="Sign in">
    Go to [app.omnara.com](https://app.omnara.com). Onboarding creates your first organization and project.
  </Step>
  <Step title="Add a model provider">
    In **Overview > Model providers**, add a provider and choose the credential secret that contains its API key.

    The provider name and model name are the values you reference from agent configs.
  </Step>
  <Step title="Create a profile">
    Open your project, then choose **Agent profiles > New agent profile**. Give it a name like `Research assistant`.
  </Step>
  <Step title="Paste the config">
    Replace `openai-prod` and `gpt-5.5` with the provider and model names from your workspace:

    ```yaml
    version: v1
    name: Research assistant
    instruction: |
      Research the questions the user sends you. Use web search for
      current information, cite sources, and ask for clarification when needed.
    model:
      provider_config: openai-prod
      name: gpt-5.5
    tools:
      web_search: {}
      web_fetch: {}
      ask_question: {}
    ```

    Save the profile. Omnara validates the model and tools before the profile can launch agents.
  </Step>
</Steps>

## Launch it

<Steps>
  <Step title="Start an agent">
    In your project, choose **Agents > New agent**. Select the profile you just created.
  </Step>
  <Step title="Send the first message">
    Use a concrete task:

    ```text
    What changed in EU AI regulation this year? Cite sources and ask me if the scope is unclear.
    ```
  </Step>
  <Step title="Watch the timeline">
    Open the agent. The timeline shows the input, model output, tool calls, tool results, and any human interactions.
  </Step>
  <Step title="Answer if it asks">
    If the agent needs a decision or clarification, resolve the interaction in the console. The agent resumes from the same turn.
  </Step>
</Steps>

## Connect: deploy to Slack

On the profile row, choose **Deploy to... > Slack** and complete the install flow. After the Slack app is installed, mentioning the agent in a channel launches a fresh agent from that profile.

Slack is just one launch surface. The same profile can also be launched from the console or API.

## API users

Create an API key in the console, then use the [API reference](/api/overview) to create configs, launch agents, stream events, and resolve interactions programmatically.
