# Omnara Documentation

Mintlify documentation published to [docs.omnara.com](https://docs.omnara.com/).

## Development

```bash
npx mintlify dev
```

## API reference

The endpoint pages are generated by Mintlify at build time from the published
copy of the spec. The `API Reference` group in `docs.json` sets `openapi` to
`api-reference/openapi.yaml`, so Mintlify creates one page per operation,
grouped by OpenAPI tag, alongside the hand-written overview page — there is no
hand-maintained endpoint list.

After any change to the canonical spec (`api/openapi/openapi.yaml`), refresh the
published copy:

```bash
make docs-openapi
```

The spec declares the hosted `https://api.omnara.com/v1` server, which
enables the Mintlify playground.

Operations tagged with `x-hidden: true` in the spec (the machine-daemon
transport routes) are excluded from the generated nav — they're the internal
daemon protocol, not public API surface — but remain in the downloadable spec.
