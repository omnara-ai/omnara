---
title: In-app guide
description: An agent inside your web app that shows your users how to do things on the page they are on
icon: "arrow-pointer"
---

Your users ask how to do something, and a cursor moves to the right control on the page they are on, highlights it, and tells them what to do, one step at a time. The guide answers from your product's own documentation. It can also do the steps for them, asking approval before anything that saves, sends, pays, or deletes. Every user of your app gets their own agent profile and conversation history, and you can read each conversation in the dashboard.

<img src="/images/examples/in-app-guide.gif" alt="The guide walking a user through inviting a teammate" />

The agent's tools are [custom tools](/tools/custom) that run in the user's browser: Omnara holds each call until the guide's widget moves the cursor, waits for the click, and posts the result back. Your app adds one component (or one script tag) and one server route that holds the Omnara API key.

## Build it

Give this prompt to Claude Code, Codex, Cursor, or any other coding agent, in your app's repository. It reads your app, asks for the product name and whether the guide may act or only show, then adds the guide and checks it on your app with you.

```text
Read https://raw.githubusercontent.com/omnara-ai/omnara/main/examples/in-app-guide/SKILL.md and follow it to add an in-app guide to this app.
```

## Where it learns your product

| Your product has | How the agent reads it |
| --- | --- |
| A docs site with an MCP server | The [MCP server](/tools/mcp)'s search and read tools |
| A public docs site | The built-in [`web_fetch`](/tools/built-in#web_fetch) tool |
| Markdown files, such as a `docs/` folder | A [memory store](/agents/configuration#memory-stores), searched and read with the built-in file tools |
| Nothing written down | Notes your coding agent writes from your app's code and screens, plus the page itself |

See [`examples/in-app-guide`](https://github.com/omnara-ai/omnara/tree/main/examples/in-app-guide) on GitHub for how it works and what it has and hasn't been tested on.
