Describe a bug, paste an error, or link an issue in Slack or Discord, or mention it on a GitHub pull request, and it works on a fresh clone of your GitHub repository, makes a focused fix, and opens a pull request. Reply in the thread to ask for changes, and it splits larger tasks across copies of itself.

## Deploy

Give this prompt to Claude Code, Codex, Cursor, or any other coding agent. It walks you through setup, creates the agent in your Omnara project, and connects it to Slack.

```text
Read https://raw.githubusercontent.com/omnara-ai/omnara/main/examples/slack-coding-agent/SKILL.md and follow it to deploy the Slack coding agent.
```

To see how it works or adapt it, browse [`examples/slack-coding-agent`](https://github.com/omnara-ai/omnara/tree/main/examples/slack-coding-agent) on GitHub.
