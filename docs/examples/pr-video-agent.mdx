A GitHub App that shows reviewers a pull request working. When a pull request changes something visible in the browser, it checks out the branch, runs your app on its own machine, clicks through the change in Chrome, and posts a short recording as a comment. It stays silent on pull requests with nothing to see, such as documentation, tests, and refactors. After a new push it records again only when the push changes what a reviewer would see, and it never records the same commit twice.

The recording is posted as a GIF from the App, stored on a hidden ref in your repository, or as a playable video from a personal access token. GitHub accepts video uploads only from a person's token, so the example offers both.

## Deploy

Give this prompt to Claude Code, Codex, Cursor, or any other coding agent. It asks which repository and when the agent should record, works out how to run your app, creates the agent in your Omnara project, and walks you through registering its GitHub App.

```text
Read https://raw.githubusercontent.com/omnara-ai/omnara/main/examples/pr-video-agent/SKILL.md and follow it to deploy the PR video agent.
```

To see how it works or adapt it, browse [`examples/pr-video-agent`](https://github.com/omnara-ai/omnara/tree/main/examples/pr-video-agent) on GitHub.
