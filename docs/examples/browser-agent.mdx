---
title: Browser agent
description: A long-running agent that signs in to your web apps and works in a real browser, overnight if needed
icon: "globe"
---

It signs in to your web apps with credentials stored as Omnara [secrets](/organization/secrets), then works in a real browser: pulling data out of dashboards, filling in forms, or working through a queue overnight. It can run one set job on a schedule or take whatever tasks your team sends it in Slack, with screenshots in its updates. Passwords never pass through the model, and it enters authenticator app codes itself, so it can sign in unattended. It runs on a large machine that's kept, browser and sign-ins included, until you archive the agent, and it asks before anything you haven't allowed it to do on its own.

## Build it

Give this prompt to Claude Code, Codex, Cursor, or any other coding agent. It asks about the work, which sites the agent signs in to and how, whether it runs on a schedule, and whether you want it in Slack. Then it builds the agent in your Omnara project and has it sign in to each site once.

```text
Read https://raw.githubusercontent.com/omnara-ai/omnara/main/examples/browser-agent/SKILL.md and follow it to build my browser agent.
```

See [`examples/browser-agent`](https://github.com/omnara-ai/omnara/tree/main/examples/browser-agent) on GitHub for how it works and what to do if a site blocks it.
