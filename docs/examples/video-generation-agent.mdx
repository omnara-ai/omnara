Describe the video you want and it builds it in code with [Remotion](https://www.remotion.dev), reviews stills from its own render to catch clipped text and glitches, and delivers the MP4. Reply to ask for changes, or attach a logo or music for it to use. It needs no API keys, only a machine pool, and defaults to Claude Opus 5.5.

## Deploy

Give this prompt to Claude Code, Codex, Cursor, or any other coding agent. It walks you through setup, creates the agent in your Omnara project, and has it make a first video.

```text
Read https://raw.githubusercontent.com/omnara-ai/omnara/main/examples/video-generation-agent/SKILL.md and follow it to deploy the video generation agent.
```

To see how it works or adapt it, browse [`examples/video-generation-agent`](https://github.com/omnara-ai/omnara/tree/main/examples/video-generation-agent) on GitHub.
