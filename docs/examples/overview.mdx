This section combines guided walkthroughs with complete projects from the repository's [`examples/`](https://github.com/omnara-ai/omnara/tree/main/examples) directory.

| Example | What it builds | What it teaches |
| --- | --- | --- |
| [`x-signal-agent`](https://github.com/omnara-ai/omnara/tree/main/examples/x-signal-agent) | Describe what to track and it searches X (Twitter), delivering a digest of the relevant posts — use it to find customers, watch competitors, or follow anything you're curious about. | The full SDK loop: secrets, configs, profiles, event streams, Slack, cron |
| [`reddit-signal-agent`](https://github.com/omnara-ai/omnara/tree/main/examples/reddit-signal-agent) | The same daily digest for Reddit — no Reddit API key or approval process; it sweeps keyword searches plus the new-post feeds of the subreddits where your audience lives | An MCP server as the entire fetch layer: an Apify-hosted scraper with bearer-secret auth, async runs (start → poll → fetch), no machine pool |
| [`linkedin-signal-agent`](https://github.com/omnara-ai/omnara/tree/main/examples/linkedin-signal-agent) | A daily digest of LinkedIn posts on your topic — no LinkedIn API, account, or session cookie; keyword search plus tracked company and profile feeds | Two scrapers behind one MCP server URL, budgeted on pay-per-result actors |
| [`posthog-pulse-agent`](https://github.com/omnara-ai/omnara/tree/main/examples/posthog-pulse-agent) | Your product analytics, delivered daily — active users, event volume, and anomalies from PostHog | Remote MCP servers: bearer auth, tool filtering, no machine needed |
| [Machine with mounted storage](/examples/mounted-storage) | An agent with filesystem access to a SharePoint document library | Bring-your-own machines: daemon in a container, mounts, targeting a machine by name |
| [`unikraft-machine`](https://github.com/omnara-ai/omnara/tree/main/examples/unikraft-machine) | A Unikraft Cloud machine image carrying the Omnara daemon | Building custom pool images |

If you're evaluating Omnara, start with the [Quickstart](/quickstart).
