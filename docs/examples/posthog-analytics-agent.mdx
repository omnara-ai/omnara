Queries your PostHog project through PostHog's MCP server and reports yesterday against the trailing 7-day average: active users, top events, and anything unusual. It's read-only against PostHog.

## Deploy

Give this prompt to Claude Code, Codex, Cursor, or any other coding agent. It walks you through setup, creates the agent in your Omnara project, and runs it once.

```text
Read https://raw.githubusercontent.com/omnara-ai/omnara/main/examples/posthog-analytics-agent/SKILL.md and follow it to deploy the PostHog analytics agent.
```

To see how it works or adapt it, browse [`examples/posthog-analytics-agent`](https://github.com/omnara-ai/omnara/tree/main/examples/posthog-analytics-agent) on GitHub.
